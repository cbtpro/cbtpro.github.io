### 折叠代码\日志

```xml

  <summary>展开查看</summary>

      console.log('hello world!')

```

🔍 预览

```arduino
console.log('hello world!')
```

还可以指定语言，使用`class="language-xxxx"`来指定语言。

```xml

  <summary>展开查看</summary>

    <code class="language-javascript">
console.log('hello world!');

    <code class="language-typescript">
print(12)

```

### 🔍 预览

```javascript
console.log('hello world!');
```

```typescript
console.log('hello world!');
```

### 嵌入Markdown

### 使用 YAML 前置数据块设置代码高亮样式

在文章头部使用highlight指定高亮样式，可以在编辑菜单中选择。

![image.png](/assets/images/7535505949504454702-3.jpg)

会在文章自动生成描数据块，文章的markdown会应用相应的样式。

```yaml
---
highlight: arta
---
```

折叠多个代码块

```xml

    <summary>环境变量说明</summary>
    <pre><code>PORT=3000</code></pre>

    <summary>构建命令</summary>
    <pre><code>npm run build</code></pre>

```

🔍 预览

```ini
PORT=3000
```

```arduino
npm run build
```
