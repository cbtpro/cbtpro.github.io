Dingo-VSCode插件，是下载仓库、阅读代码的vscode极佳伴侣

官网地址 [wallabyjs.com/dingo/](https://wallabyjs.com/dingo/)

插件市场 [marketplace.visualstudio.com/items?itemN…](https://marketplace.visualstudio.com/items?itemName=WallabyJs.dingo-vscode)

他允许您直接从VS Code里下载并打开Git存储库。

支持以下存储库位置/格式:

NPM包名(例如lodash)
GitHub存储库URL(例如[github.com/lodash/loda…](https://github.com/lodash/lodash))
Git HTTP端点(例如[github.com/lodash/loda…](https://github.com/lodash/lodash.git))
Git SSH端点(例如[git@github.com](mailto:git@github.com):lodash/lodash. Git)

![demo.gif](/assets/images/7348726802448449573-1.jpg)

可以用来快速从git仓库上clone项目，支持证书、accesskey、用户名密码等多种验证方式，免费。他还的另外两款插件你也许用过：Quokka.js\Console Ninija。

使用方法打开vscode的命令面板，window使用快捷键`Ctrl + Shift + P`，mac用户使用`Command + Shift + P`，输入命令`>Dingo: Open`，按照步骤来即可。
