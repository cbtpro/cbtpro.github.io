Dingo-VSCode插件，是下载仓库、阅读代码的vscode极佳伴侣

官网地址 wallabyjs.com/dingo/

插件市场 marketplace.visualstudio.com/items?itemN…

他允许您直接从VS Code里下载并打开Git存储库。

支持以下存储库位置/格式:

NPM包名(例如lodash) GitHub存储库URL(例如github.com/lodash/loda…) Git HTTP端点(例如github.com/lodash/loda…) Git SSH端点(例如git@github.com:lodash/lodash. Git)

![](/assets/images/dingo-demo.gif)

可以用来快速从git仓库上clone项目，支持证书、accesskey、用户名密码等多种验证方式，免费。他还的另外两款插件你也许用过：Quokka.js\Console Ninija。

使用方法打开vscode的命令面板，window使用快捷键Ctrl + Shift + P，mac用户使用Command + Shift + P，输入命令>Dingo: Open，按照步骤来即可。
